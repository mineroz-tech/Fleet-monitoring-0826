Petunjuk Penggunaan

Cara pakai Fleet Command — dari upload data sampai baca hasil analisa

Semua proses baca & olah data Excel berjalan langsung di browser kamu (tidak diunggah ke server manapun). File hanya perlu dibuka ulang untuk melihat data terbaru — aman dipakai untuk data operasional internal.
Bar "Rentang" di bawah topbar (muncul di tab Dashboard, Daily Monitoring, PA/MA/UA/Util, dan Delay & Pareto) memfilter data berdasarkan tanggal — pilih preset Harian / Mingguan / Bulanan / Tahunan, atau Custom untuk rentang tanggal bebas. Data master (Unit Master, Service Schedule, Forecast) tidak ikut terfilter karena itu menampilkan kondisi & jadwal PM terkini, bukan histori periode tertentu.

Mulai Cepat

4 langkah dasar memakai aplikasi ini
1

Upload data Excel — bisa satu atau beberapa bulan sekaligus

Klik tombol "Upload Data Excel" di sidebar kiri, lalu pilih satu file atau beberapa file sekaligus (misalnya Juni, Juli, Agustus) — tahan Ctrl (Windows) / Cmd (Mac) saat memilih file di dialog upload. Aplikasi otomatis menggabungkan log harian dari semua file berdasarkan tanggal secara kronologis, sementara data master (kondisi unit & status PM) memakai snapshot dari file dengan tanggal data paling baru. Format tiap file harus sama seperti template — ada sheet "Rekapitulasi" dan satu sheet per unit untuk log harian.

2

Cek Dashboard untuk gambaran umum

Lihat KPI utama (total unit, kondisi fleet, rata-rata PA/MA/Utilisasi), tren harian, komposisi fleet, dan alert unit yang butuh perhatian — semua ke-summary di satu layar.

3

Gali detail lewat tab lain

Buka Unit Master untuk data tiap unit, Daily Monitoring untuk log harian mentah, PA/MA/UA/Util untuk reliability per unit, Delay & Pareto untuk cari penyebab downtime terbesar, dan Service Schedule untuk jadwal & forecast PM.

4

Susun laporan & export

Ke tab Report Center untuk generate laporan siap cetak (per unit / kategori / seluruh fleet), atau pakai tombol Export CSV yang tersedia di hampir tiap tabel untuk ambil datanya ke Excel.

Penjelasan Tiap Tab

Apa isinya dan kapan dipakai

Dashboard

Ringkasan kondisi fleet secara keseluruhan.

  • Alert strip di atas — daftar unit yang butuh perhatian (down, PM overdue, kontrak habis, PA rendah).
  • KPI card — total unit, komposisi kondisi, rata-rata PA/MA/Utilisasi fleet.
  • Trend chart — pergerakan PA/MA/Utilisasi harian sepanjang periode data.
  • Ranking — unit dengan PA terendah dan utilisasi tertinggi, plus frekuensi breakdown per unit.

Unit Master

Daftar lengkap seluruh unit terdaftar, bisa ditampilkan sebagai tabel atau grid kartu.

  • Gunakan kolom pencarian & filter (kondisi, tipe, kategori) untuk mempersempit daftar.
  • Klik header kolom untuk urutkan (misal urutkan berdasarkan PA terendah).
  • Klik baris/kartu unit untuk buka detail unit — profil, KPI, log harian, dan grafik trend khusus unit itu.

Daily Monitoring

Log input harian mentah dari semua unit — satu baris per unit per hari.

  • Cari berdasarkan unit, operator, atau isi remarks.
  • Filter berdasarkan unit, status (Working/Mechanical Down/Physical Down), atau kategori downtime.
  • Cocok dipakai untuk audit atau menelusuri kejadian spesifik di tanggal tertentu.

PA / MA / UA / Util

Analisa reliability per unit secara lebih dalam.

  • Pilih unit dari dropdown untuk lihat trend PA/MA/Utilisasi harian dan breakdown jam kerja (working/standby/downtime).
  • Ranking PA seluruh unit membantu bandingkan performa antar unit sekaligus.
  • Tabel frekuensi & rata-rata downtime per kejadian berguna sebagai indikasi keandalan (mirip MTBF/MTTR) untuk unit yang punya log harian.

Delay & Pareto Analysis

Mencari akar masalah downtime terbesar di seluruh fleet.

  • Grafik Pareto menunjukkan kategori downtime mana yang paling banyak makan jam — fokuskan perbaikan di kategori paling kiri (kontribusi terbesar) dulu.
  • Tabel detail memberi angka pasti tiap kategori: kejadian, total jam, persen kontribusi, kumulatif.
  • Panel "Unit Paling Sering Delay" menunjukkan unit mana yang paling sering tidak dalam status Working.

Service Schedule

Jadwal & forecast preventive maintenance (PM) seluruh fleet.

  • Gantt chart — tiap baris unit, tiap kolom hari; warna menunjukkan status harian unit, titik di atas menandai tanggal PM jatuh tempo.
  • Forecast Service — dihitung otomatis dari kolom HM Akhir terbaru di log harian. Interval PM bisa diatur langsung (default 250 jam untuk Heavy Equipment, 5.000 km untuk Light Vehicle/Support) — ubah angkanya lalu klik "Terapkan", pengaturan akan tersimpan di browser.
  • Program PM per Unit — status pasti PM1–PM4 tiap unit (Overdue/Due Soon/Scheduled/Done/Scrap) sesuai data dari sheet Rekapitulasi.

Report Center

Susun laporan ringkas siap cetak.

  • Pilih cakupan: seluruh fleet, satu unit tertentu, atau per kategori (Heavy Equipment/Light Vehicle).
  • Klik Generate untuk menyusun, lalu Print / PDF untuk mencetak atau simpan sebagai PDF lewat dialog print browser.

Pertanyaan Umum

Klik pertanyaan untuk lihat jawabannya
Bisakah upload beberapa file Excel bulanan sekaligus?
Bisa. Saat memilih file di dialog upload, pilih lebih dari satu file (tahan Ctrl/Cmd, atau seleksi rentang dengan Shift). Aplikasi akan menggabungkan log harian seluruh file secara kronologis per tanggal (kalau ada tanggal yang tumpang tindih antar file, data dari file dengan tanggal terbaru yang dipakai), sehingga trend chart, Gantt, dan forecast bisa mencakup rentang beberapa bulan sekaligus. Data master (kondisi unit & status PM di sheet Rekapitulasi) akan memakai snapshot dari file yang datanya paling baru, karena itu mencerminkan kondisi unit terkini.
Kenapa saat upload muncul "File tidak dikenali"?
Aplikasi mencari sheet bernama "Rekapitulasi" untuk data master, dan sheet-sheet lain (satu per unit) untuk log harian. Kalau nama sheet atau susunan kolomnya beda dari template asli, data tidak akan terbaca dengan benar. Pastikan file yang diupload masih memakai struktur yang sama.
Kenapa ada unit yang tidak muncul di Gantt chart / Forecast Service?
Gantt chart dan Forecast Service butuh log harian per unit (sheet tersendiri per unit). Unit yang hanya terdaftar di sheet Rekapitulasi tanpa sheet log harian akan tetap muncul di Unit Master dan Program PM, tapi ditandai "Tidak ada log harian" di Gantt dan "Belum Ada Data Meter" di Forecast.
Bagaimana aplikasi mencocokkan sheet unit ke data master?
Otomatis — dicocokkan berdasarkan Unit ID (dinormalisasi, jadi beda format spasi/tanda baca tetap terbaca sama). Kalau Unit ID persis tidak ketemu, aplikasi coba cocokkan sebagian teks Unit ID, dan sebagai upaya terakhir cocokkan nama sheet dengan nama/tipe unit. Jadi file bulan berikutnya dengan struktur sama akan tetap terbaca otomatis tanpa perlu pengaturan ulang.
Apakah interval PM yang saya ubah akan hilang kalau ditutup?
Tidak — interval tersimpan di browser (localStorage) begitu tombol "Terapkan" diklik, jadi tetap kepakai walau tab/aplikasi ditutup dan dibuka lagi di komputer yang sama. Kalau dibuka di komputer lain, interval kembali ke default (250 HM / 5.000 KM) sampai diatur ulang.
Apakah data yang saya upload tersimpan otomatis?
Ya — setiap kali upload berhasil, data langsung tersimpan otomatis di browser (localStorage) di komputer itu. Jadi kalau aplikasi/tab ditutup lalu dibuka lagi filenya di komputer yang sama, data terakhir yang diupload akan otomatis termuat, bukan data bawaan file. Indikator hijau "Tersimpan otomatis" di sidebar menunjukkan kapan terakhir disimpan. Untuk kembali ke data bawaan file ini, klik tombol "Reset" di sebelah indikator tersebut. Autosave ini khusus untuk komputer/browser itu saja — kalau file HTML-nya dibuka di komputer lain, yang muncul tetap data bawaan sampai upload ulang di sana.
Kenapa estimasi tanggal servis di Forecast kadang kosong?
Estimasi tanggal butuh rata-rata pemakaian harian (dari selisih HM sepanjang periode). Kalau data historis unit tersebut terlalu sedikit atau tidak menunjukkan kenaikan meter yang jelas, aplikasi menampilkan "Belum bisa diestimasi" — sisa HM/KM sampai servis berikutnya tetap dihitung dan ditampilkan meski tanggalnya belum bisa diperkirakan.
Bagaimana cara sembunyikan sidebar untuk layar lebih lega?
Klik tombol panah bulat di tepi kanan sidebar untuk menciutkannya jadi mode ikon. Untuk membuka lagi, klik ikon hamburger kecil yang muncul di pojok kiri atas topbar.
